# R8.0 — StopCoordinator：统一停止机制与控制权交接

> 目标：任何入口（F8 / DSH-MCP / 游戏 stop 开关 / 插件卸载 / Agent 空转）发出的停止，都只有**一套**协调机制；
> 停止得到可靠确认之前，旧执行链不能继续行动，新执行链也不能接管角色。

## 1. 职责与 API

`lib/control/stop-coordinator.js`，**纯协调层**：不碰游戏，底层停止仍由
`WorldRuntime → Dispatcher → GameBridge → Lua Guard → Lua Actions` 完成。

```js
class StopCoordinator {
  requestStop({ source, reason, timeoutMs, requester, releaseLease }) → Promise<StopResult>
  getStatus()            // { phase, generation, quarantined, stopping, canAcceptNewWork, last, diagnostics }
  isStopping()
  canAcceptNewWork()
  waitForStopped({ timeoutMs })
  tryRecover()           // 仅当 Runtime 锁真实释放才解除隔离
}
```

`StopResult`：`{ ok, status: 'stopped'|'unknown'|'refused'|'idle', phase, generation, command_id,
active_task_id, active_instance_id, quarantined, next_action_allowed, detail }`。

### 状态机
```
idle → stop_requested → rejecting_new_work → cancelling_agent → cancelling_skill
     → dispatching_stop → awaiting_lua_ack → awaiting_runtime_release → stopped
异常：任意阶段超时/未确认 → stop_unknown → quarantine →（锁真实释放后）tryRecover → idle
```

### 关键不变量（红线）
1. 停止未确认前**不释放 Lease**、**不开放交接**（`releaseLease` 仅在 `confirmed` 后回调）。
2. 超时 ≠ 成功：`unknown + quarantined`，保持 `cancelRequested`。
3. 同一次停止（同世代并发）合并为**同一个 Promise**，只执行一次。
4. 隔离只能由「Runtime 锁真实释放」解除，不能用超时清标志。
5. 所有底层动作仍只经 Dispatcher + Lua Guard（无第二执行通道、无 `force:true` 抢占）。

## 2. 统一调用路径

```
F8 关闭(toggle.ai=false) ─┐
游戏 stop 开关(toggle.stop) ─┤
DSH-MCP stop 工具 ─────────┼─→ StopCoordinator.requestStop()
stop_tool / agent_idle ────┤        │
插件卸载 ──────────────────┘        ▼
                           rejecting_new_work → cancelling_agent(Agent.stop/waitIdle)
                           → cancelling_skill → dispatching_stop(以**租约持有者**身份)
                           → awaiting_lua_ack → awaiting_runtime_release → stopped
                           → (确认后) releaseLease / 交接
```

- **F8 关闭**：`requestStop({source:'f8_toggle'})`，不再 `runner.stop()+control.release()`。
- **游戏 stop 开关**：`requestStop({source:'game_stop_switch'})`，停止确认后再 `control.acquire('manual_test')` 人工接管；不再 `force:true` + 裸 `bridge.call('stop')`。
- **DSH-MCP**：`executeTool('stop')` 特判，**跳过 `acquireWithWait`**，直接 `requestStop({source:'mcp_stop',requester:'mcp_client'})`；`runTool` 的 `ACTION_NAMES` 门放行 `stop`。
- **stopTool**：`ctx.stopCoordinator` 存在时走协调器（所有 stop 工具归一），否则保留 `runtime.stop` 降级。
- **Agent 空转**：`AiRunner.onSelfStop` 钩子 → `requestStop({source:'agent_idle'})`。
- **插件卸载**：cleanup 调 `requestStop({source:'plugin_unload'})`（尽力而为，不阻塞卸载）。

## 3. AbortSignal 传播路径

```
StopCoordinator.cancelling_skill
   → WorldRuntime.stop(): activeAbortController.abort('stopped_by_user')
   → TaskSkillOrchestrator.tickOnce({signal})
   → SkillExecutor.run({signal})
   → Dispatcher.dispatch({signal})   (下发前检查 aborted；透传给 bridge.call)
   → 取消尚未发送/等待中的 Node 侧命令
Agent 层：AiRunner.stop() 中止模型 HTTP（#controller.abort）+ runId 世代化阻止旧回调再派发
```

## 4. Runtime 锁与 Lease 释放条件

- **Runtime 锁**：`WorldRuntime.stop` 有界等待 `currentLockOwner` 为空（`#releaseLock` 只在 owner 匹配时释放，旧任务 finally 不会误放新锁）。
- **Lease**：仅当 `confirmed = (stop 结果 succeeded) && (Runtime 锁已释放)` 后，由 `StopCoordinator.releaseLease({holder})` 释放**当前持有者**的租约；否则保持不释放、进入隔离。
- 隔离解除：`#releaseLock` 在锁真实释放时清除 `quarantined/cancelRequested`；`StopCoordinator.tryRecover()` 同步解除自己的隔离态。

## 5. stop ACK 的含义与判定

- **命令 ACK**（`whale_result.json`，`{id: command_id, ok, text, reason}`）来自 Lua：`JOBS.stop → A.stop_actions`（`loco:Stop/Clear`、`ClearBufferedAction`、`hold_control(false)`、`client_stop`）跑完一帧后 `Report(true,'停下了')`；若旧 job 在跑，`A.Start('stop')` 会先 `stop_actions` 并向旧 `cmd_id` 报「被新指令打断」（Reflex 除外，`A.Start` 直接拒绝）。
- **判定**：`confirmed` 需要①dispatcher 结果 `status==='succeeded'`；②Runtime `currentLockOwner===null`。任一不满足 → `unknown`。`ok:true`（命令回执）本身**不等于**整体停止成功，必须叠加锁释放。
- **Reflex 保护**：`dispatcher` 允许 stop 穿透 reflex（`reflex && tool!=='stop'` 才拒普通动作）；但 Lua `A.Start` 对 `job.cmd_id=='reflex'` 拒绝非 reflex 打断 → 返回 `cancelled/reflex_active`，协调器记为 `refused`（不隔离、不释放）。
