# R8.2：Wendy First —— 温蒂首发角色档案与阿比盖尔协同

> 状态：**代码 + Fengari 单测已落地；真机未验证**。本阶段交付的是"能识别温蒂 / 理解阿比盖尔 / 用温蒂式策略"的可扩展角色系统，不是让温蒂独立通关。

## 1. 已核实的游戏机制（来源：仓库自带 `.runtime/dst-scripts`）

- 温蒂：`prefabs/wendy.lua` → `MakePlayerCharacter("wendy")`；`WENDY_HEALTH/HUNGER/SANITY = wilson 150/150/200`；
  `sanity.night_drain_mult = sanity.neg_aura_mult = TUNING.WENDY_SANITY_MULT(0.75)`（理智流失×0.75）；
  `combat.damagemultiplier = TUNING.WENDY_DAMAGE_MULT(0.75)`（本体伤害×0.75）。
- 阿比盖尔：`prefabs/abigail.lua` / `abigail_flower.lua`；由玩家 `components.ghostlybond.ghost` 绑定，prefab `"abigail"`；
  等级 1/2/3 血量 `ABIGAIL_HEALTH_LEVEL1/2/3 = 150/300/600`；`abigail_flower` 召唤/召回。
- 蜘蛛：`SPIDER_HEALTH=100 / SPIDER_DAMAGE=20`；`spider_warrior=400/20`；`spiderqueen=2500/80`；
  真实 prefab：`spider / spider_warrior / spider_healer / spider_hider / spider_moon / spider_water / spiderqueen`。

## 3. Profile 接口

```lua
local prof = Whale.character.Resolve(player)   -- 按真实 prefab 自动识别；未知回退 base
prof.id / prof.prefab / prof.display_name
prof.GetSanityPolicy(player)    -- { warn, critical, drain_mult, note }
prof.GetCombatPolicy(player)    -- { preferred_strategy, allow_spider_hunt, requires_companion_for_hunt, avoid_melee, damage_mult }
Whale.character.GetCompanionState(player)  -- { present, alive, valid, distance, health_percent,
                                           --   current_target, is_following, is_attacking, is_busy, can_assist, unknown }
Whale.character.ClassifyEnemy(prefab)      -- { kind: spider_common|spider_warrior|spider_queen|other, hunt_allowed, risk }
```
- 角色切换/玩家实体变化按 prefab **即时**解析；不同角色阈值互不污染；未识别一律 base，不崩。
- Profile 不建立第二套动作系统，一切仍走 `Whale.actions → Dispatcher → Lease → Guard`。

## 4. 温蒂专属策略

- 生存：继续用统一 Local Survival Brain；理智阈值略低（0.50，因×0.75 流失），**理智尚可时不要无事采花**，需要时只就近安全采花。
- 战斗：`preferred_strategy = abigail_assisted`；本体伤害×0.75，**别当普通近战硬砍**；`requires_companion_for_hunt = true`
  ——阿比盖尔不在/死亡/无法协助时，`battle` 起手直接 `companion_not_ready`，不主动送。

## 5. 阿比盖尔状态管理

`GetCompanionState` 从 `player.components.ghostlybond.ghost` 读取，字段全部来自真实组件；读不到即 `unknown=true`，绝不伪造"可协助"。
用于：observe 展示、LLM 判断、battle 起手闸。**无重复召唤逻辑**（召唤仍走现有 `abigail_flower` 机制 / LLM 决策；本阶段未新增召唤动作，先依赖现有物品与动作）。

## 6. 蜘蛛战斗协同

- 复用现有 `battle.lua`：已有 spider/spider_warrior 策略、`find_best_spider_target`、Boss 黑名单（含 spiderqueen）、掉落优先级。
- 新增：`battle.StepJob` 起手按 `GetCombatPolicy().requires_companion_for_hunt` 校验阿比盖尔 `can_assist`；不满足则 `companion_not_ready`。
- `ClassifyEnemy` 用真实 prefab 分类：普通蜘蛛可猎；蜘蛛战士/治疗/洞穴/月/水保守不主动；蜘蛛女王绝不主动；其它/未知默认保守。
- 主动狩猎仍由 Agent 目标/用户任务触发；Lua 负责战斗中的安全与角色适配（非每帧自动找蜘蛛开战）。
