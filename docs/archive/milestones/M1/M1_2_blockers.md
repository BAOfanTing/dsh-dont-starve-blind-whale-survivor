## 2. 最少人工步骤（推荐路线：用你自己的客户端开一个测试世界）

> 全程约 3 分钟；**建议用一个新的测试世界**，不要用重要存档（虽然本轮确认安装脚本不碰存档）。

1. 打开 Steam →《饥荒联机版》→「创建世界」→ 选 `标准/生存`、把 `洞穴` 先关掉（双分片留到 B8）→ 进入世界。
   - 模组已在 `mods/` 里且 `modsettings.lua` 已 `ForceEnableMod`，进世界应自动加载（版本 0.12.1）。
2. **不要按 F8**（F8 会让 AI 自己下指令），我们要的是只读采样。
3. 回到这个仓库目录，跑：
   ```powershell
   node tools/m12-watch.mjs --seconds 60
   ```
   它只读状态文件，不会给游戏发动作。结束会在 `tests/artifacts/M1_2/` 生成 `runtime-*.json` 和 `runtime-*.md`。
4. 把 `runtime-*.md` 贴给我（或直接说"跑完了"），我来判读：新格式字段、`actor_id_kind`、
   三围/背包是否与画面一致、写盘间隔、`reused`、legacy/stale。
5. 想做 Session 对比（B7）：退出世界 → 再进一次 → 再跑
   `node tools/m12-watch.mjs --seconds 20`。
6. 想做双分片（B8）：在世界里造/走一个洞穴入口下去，再跑一次采样。

**顺便能验证的两件事（1 分钟内）**：
- 游戏里按 **F7**（只停手，不触发 AI 循环），看小窗是否变成"停着"——验证客户端侧 HUD 与按键链路；
- 确认游戏日志 `master_server_log.txt` 里出现 `[大肥饿不死] 文件桥已启动（服务端）：写 whale_state.json`，
  且**没有** `error calling ... in mod`。
