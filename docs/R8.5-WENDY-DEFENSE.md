# R8.5：温蒂伴生战斗闭环（蜘蛛 / 青蛙防御 + 阿比盖尔主动参战）

> 基线：`main` @ `f860c04`（模组 0.41.2）→ 本阶段 **0.41.3**
> 构建标识：`0.41.3+r8.5-wendy-defense`（状态文件 `build` 字段 + server_log `[BUILD]` 行）

## 1. 要解决的真机问题

最新日志里温蒂第 1 天：

1. 背包有阿比盖尔之花，但**阿比盖尔一直没召唤**；
2. 两只青蛙靠近后，Lua Reflex **反复启动 flee**；
3. 温蒂生命 150 → 130；
4. 之后附近三只青蛙（约 3.6 / 5.5 / 5.9 格），`advance_task` 多次被 `reflex_active` 阻断；
5. 阿比盖尔之花从背包消失，随后在地面 `(25,-58)` 被观察到（青蛙命中击落背包物品）；
6. 角色长时间没有伴生，食物问题逐渐恶化。

**根因（读源码确认，不是猜）**：

| 问题 | 位置 | 说明 |
|---|---|---|
| 只为猎犬启动防御 | `reflex.lua` | 只有 `hound / icehound / firehound` 调 `B.StartDefense`，普通蜘蛛/蜘蛛战士/青蛙一律走 flee |
| 青蛙没有策略 | `battle.lua` `STRATEGIES` | 没有 `frog`，无法进入受控防御 |
| 绕过 summon 任务 | `battle.lua` `StartDefense` | 直接 `BufferedAction(p, nil, ACTIONS.CASTSUMMON, flower)` + `A.push`，绕过 `JOBS.summon_companion` 的契约/花朵/已召唤/超时核验 |
| 防御永远接不上 | `actions/core.lua` `A.Start` | `job.cmd_id == "reflex"` 时禁止任何非 reflex 打断；而 flee 本身就是 reflex job ⇒ 防御永远无法交接 |
| `avoid_melee` 没落地 | `battle.lua` ATTACK | 即使阿比盖尔在场，ATTACK 阶段仍调 `native.AttackAction(p, target)`，温蒂自己挥砍 |
| 三只怪必然撤退 | `battle.lua` 群怪守卫 | `count_attackers_targeting > 1` 即紧急中止，不区分"伴生能否扛" |
| 花捡不回来 | `pickuprules.lua` | `abigail_flower` 不在拾取白名单 ⇒ 掉在地上也永远捡不起来 |

## 2. 原版机制依据（`.runtime/dst-scripts`）

- `prefabs/frog.lua`：`FROG_HEALTH=100`、`FROG_DAMAGE=10`、`FROG_ATTACK_PERIOD=1`、`runspeed=8`；
  tags `hostile/animal/prey/smallcreature/frog`；`onhitother → thief:StealItem(目标)`（**命中击落背包物品**）；
  `OnAttacked → ShareTarget(30, tag "frog")`（打一只会喊周围青蛙）。
- `brains/frogbrain.lua`：`ChaseAndAttack(MAX_CHASE_TIME=8)` ⇒ 追 8 秒，直线跑甩不掉。
- `prefabs/abigail.lua`：默认 **defensive**（`BecomeDefensive`）；`DefensiveRetarget` 只对
  `(目标在打玩家 / 玩家在打目标 / 目标在打阿比盖尔)` 且 `阿比盖尔距玩家 < ABIGAIL_DEFENSIVE_MAX_FOLLOW`
  且 `目标距玩家 < ABIGAIL_COMBAT_TARGET_DISTANCE` 的敌人接战。
  `tuning.lua`：`ABIGAIL_DEFENSIVE_MAX_FOLLOW=5`、`ABIGAIL_COMBAT_TARGET_DISTANCE=15`（世界单位，4 单位=1 格）。
- `components/ghostlybond.lua`：`summoned` / `notsummoned` / `ghost` / `bondlevel`；死亡 → `Recall(true)`。
- `actions.lua` `CASTSUMMON.fn`：要求 `invobject.components.summoningitem` + `doer.components.ghostlybond`。

**结论**：阿比盖尔的自动防御是原版能力，我们只需要"把她召出来并让温蒂别自己上"。
不需要、也不允许去改 ghost 的 `combat.target`。

## 3. 实现

### 3.1 抢占矩阵（`actions/core.lua`）

新增 `A.DEFENSE_ID = "defense"`、`A.reflex_intent()`、`A.may_preempt()`，作为**唯一**判定处：

| 当前任务 | 新任务 | 结果 |
|---|---|---|
| Reflex flee | defense | 允许受控交接（`flee_handoff`） |
| Reflex heal / eat | defense | 生命 < 35% → 拒绝（`heal_priority`）；否则重新评估后允许 |
| Reflex light / craft_light | defense | 拒绝（`light_priority`，黑暗 P0 优先） |
| 普通采集/模型指令 | defense | 允许（`preempt_ordinary`） |
| summon_companion 进行中 | defense | 拒绝（`summon_in_progress`，禁止重复召唤） |
| defense 进行中 | defense | 保持原任务（`defense_in_progress`） |
| 任意 | 非 defense 指令 | Reflex 一律不可被打断（历史 P0 保护不变） |

交接成功时显式 `job = nil; Whale.job = nil`，并 `stop_actions(p)` 清掉旧 BufferedAction，
确保**不会同时存在两个 Whale.job / 两个 BufferedAction**。

`bridge.lua`：`Report` 把 `"defense"` 与 `"reflex"` 一样写本地结果文件
（`whale_defense_result.json`），**绝不占用模型指令的结果槽**。

### 3.2 Reflex → Battle 接线（`reflex.lua`）

- 任何 `B.STRATEGIES[attacker.prefab].supported` 的敌人都先尝试 `B.StartDefense(p, attacker)`，
  不再只限猎犬。
- 返回 `"engaged" | "summoning"` → 抑制普通 flee；`"summoning"` 有界容忍：
  **超过 8 秒**或**自身血量 < 35%** 立即 `AbortDefense` 并回退逃跑（flee 永远不会被永久禁用）。
- `job_priority`：`defense` 与 `reflex` 同为 P1，不被 P2 日常维护抢走。
- 新增 P2 伴生维护（仅"无任务 + 无威胁"）：
  - 花掉在地上 → 走既有 `pickup` 动作捡回（`[COMPANION] FLOWER_DROPPED / FLOWER_RECOVERED`）；
  - 有花、未召唤、安全 → 提前召唤（`[COMPANION] SUMMON_STARTED / SUCCEEDED / FAILED`）。

### 3.3 `B.StartDefense`（`battle.lua`）—— 统一交接入口

返回 `"engaged" | "summoning" | "rejected"`：

1. Boss / 不支持目标 / 自身 < 25% → `rejected`；
2. 温蒂 + 阿比盖尔可协助 + 血量 ≥ 40% → `engaged`（启动 `fight_spider`，`cmd_id="defense"`）；
3. 温蒂 + 有花未召唤 → `A.Start("summon_companion", {}, "defense")` → `summoning`
   （**绝不再自己 push CASTSUMMON**）；失败 → `rejected` + 20 秒退避（禁止无限重试）；
4. 召唤 job 结束但阿比盖尔没出现 → `rejected` + 退避（不再"没成功就重来"）；
5. 阿比盖尔太虚（< 40%）或无花不可召唤 → `rejected`（回退撤退）；
6. 通用角色 → `engaged`。

新增 `B.DefenseStatus()` / `B.AbortDefense()` / `B.CanTolerateGroup()` 供 reflex / observe / 诊断使用。

### 3.4 真正落实 `avoid_melee`（`battle.lua` ATTACK）

`session.companion_led = avoid_melee && 伴生 alive && can_assist`（每 tick 重算）。为真时：

- **绝不**调用 `native.AttackAction`（温蒂本体不挥砍）；
- 只做位置维持（保持约 2.2~3.2 格，让原版 `DefensiveRetarget` 成立）；
- 监控：阿比盖尔血量 < 25% / 死亡 / 失去协助 → `EMERGENCY` 中止；自身 < 35% → 中止；
- **战斗有效性必须有证据**：目标血量下降才累计 `companion_hits`（不能只因"她在场"就宣称打赢）；
- 结算文案如实写"阿比盖尔打倒了 X（确认出手 N 次，温蒂未近战）"。

### 3.5 青蛙策略与群体容忍

`STRATEGIES.frog`：`swings_per_cycle=1`、`retreat_distance=3.5`、`drops_items=true`、
`share_target=true`、`fragile=true`（100 血）。**不复用蜘蛛的 2 连击**（青蛙攻速 1s、会击落物品）。

群体容忍（`B.CanTolerateGroup` / `ShouldSuppressReflex` / StepJob 群怪守卫三处**同一判据**）：

- 只统计 `combat.target == 温蒂` 的敌人（"附近有敌"不算）；
- 伴生可协助 + 伴生血 ≥ 40% + 自身血 ≥ 50% → 允许 ≤ 3 只受控群战；
- 超过 3 只、伴生虚弱、自身低血 → 立即紧急中止（保留原保命规则）。

### 3.6 阿比盖尔状态可核验（`character/companion.lua`）

补充 `guid / target_guid / distance_tiles / defensive_range`；协助半径改为
`ABIGAIL_DEFENSIVE_MAX_FOLLOW × 2`（原实现误乘 4，过宽）。
新增 `C.FindDroppedFlower(player, radius)`：只认"没人拿着、不在 limbo"的地面花。

### 3.7 花朵保护与回收

- `pickuprules.PREFABS.abigail_flower = true`（普通地面物品，可被原生 PICKUP 捡起）；
- `targetrules` 新增 kind `abigail_flower`（`pickup`）+ Node `target-kinds.js` 同步
  （`KIND_ACTION / KIND_PREFABS / GROUND_PICKUP_PREFABS / KIND_PRODUCTS`，有 parity 测试盯着）；
- `guard.lua`：`drop / fuel / add_fuel` 目标为 `abigail_flower` → `critical_item_protected`；
- 回收顺序：先解除威胁 → 再捡花 → 用真实背包状态核验（`confirm_pending`）。

## 6. 真实游戏验收（未完成，必须单独做）

`npm test` 只证明源码逻辑；**不代表真机战斗验收通过**。需要温蒂真实游戏完成：

- **A 单只普通蜘蛛**：有花未召唤 → 蜘蛛攻击 → 观察 `SUMMON_STARTED/SUCCEEDED` → `DEFENSE_ENGAGE` →
  确认温蒂**没有** `ATTACK` 动作、蜘蛛确实掉血。
- **B 青蛙池塘**：第 1 天、1~3 只青蛙 → 验证先召唤、花不掉落、单只与群体处理不同。
- **C 阿比盖尔失效**：手动召回/击杀 → 确认 `can_assist=false`、Reflex 恢复撤退。
- **D 危险中断与恢复**：战斗中压血 → 紧急退出、无残留 job，安全后恢复任务。

每个场景保存 `session.jsonl` / `session.txt` / `server_log.txt`，并用 `[BUILD]` 行确认加载的是本构建。

## 7. 架构红线（本阶段遵守情况）

- 仍然只有：Reflex / Battle → `Whale.actions` job manager → 既有 Lua Actions → Dispatcher 授权 → 原生动作；
- 没有第二套战斗执行器、没有绕过 Actions 的召唤入口（召唤走 `JOBS.summon_companion`）；
- 没有第二套伴生状态（唯一来源 `character/companion.lua`）；
- Reflex 与 Battle 不会同时下发不同动作（交接时显式清空旧 job + BufferedAction）；
- 没有为了"敢打架"而关闭 flee（< 25% / 伴生虚弱 / > 3 只 / 黑暗 仍然撤退）；
- 没有通过提示词伪装阿比盖尔已召唤或已打赢（战斗有效性以目标掉血为证据）。
