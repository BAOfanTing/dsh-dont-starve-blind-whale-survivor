# 饥荒联机版：开局生存与常见坑（主攻略）

这份攻略聚焦游戏本身的生存思路与 prefab 常识（工具清单与参数以工具列表为准）。

## 一、三件先记住的事

1. **一切以 `get_state` 为准**：你的位置、血/饥饿/理智、背包和周边资源，只有 `get_state` 知道。
2. **坐标是格子**（1 格 = 4 世界单位），写着 `(12,45)` 就传 `move_to({"x":12,"z":45})`；行动时时间连续流逝，尽量一步到位、少在原地空耗。
3. **动手优先用类别或句柄**：捡/采优先用 `*_nearest`（`target_kind`）或 `target_handle`，少传易过期的 `#N + snapshot_id`；够不着先 `move_to` 走近。

## 二、第 1~3 天开局节奏

1. **先拿火把与基础工具**：
   - 采至少 `2 cutgrass` + `2 twigs` 做 `torch`（入夜/黄昏随时备好，空手做出会自动拿在手里）。
   - 地面捡 `flint`（燧石，用 `pickup_nearest`）凑齐 `axe`（`1 twigs + 1 flint`）和 `pickaxe`（`2 twigs + 2 flint`）。
2. **储备食物，别等见底再找**：
   - 白天顺路捡地上的 `carrot`、`berries`（`pickup_food`）或采成熟浆果丛（`harvest_nearest`）。
   - 饥饿低于约 50% 就吃东西，同时背包留足备用食物；附近什么都没有再用 `seek` 出去找。
3. **找金块、选营地、建科学机器**：
   - 金矿石 `rock2`（带金纹）才能用镐（`mine`）挖出 `goldnugget`，普通大石 `rock1` 不含金。
   - 备齐 `4 log`（`chop` 常青树 `evergreen` / 桦栗树 `deciduoustree`）+ `4 rocks` + `1 goldnugget` 后，选靠近草/浆果/牛群或猪村的开阔地安家，再建 `sciencemachine` 解锁科技。
   - 建家后补 `firepit`（`2 log + 12 rocks`）、箱子 `chest`（用 `container_put` 存物资，满包时 `drop` 腾格子）和烹饪锅 `cookpot`（`3 cutstone + 6 charcoal + 6 twigs`）。

## 三、常见 prefab 对照

| 游戏里看到的东西 | prefab 名 | 备注 |
|---|---|---|
| 草 / 树苗 / 多枝树 | `grass` / `sapling` / `twiggy_tree` | 产物为 `cutgrass`、`twigs` |
| 常青树 / 桦栗树 | `evergreen` / `deciduoustree` | 装备斧头后 `chop`，掉 `log` |
| 普通石 / 金矿石 / 散落燧石 | `rock1` / `rock2` / `flint` | `rock1` 不出金；前期先捡地上 `flint` |
| 浆果丛 / 地里胡萝卜 | `berrybush`、`berrybush2`、`berrybush_juicy` / `carrot_planted` | 用 `harvest_nearest` / `pickup_food` |
| 生物与危险点 | `rabbit`、`beefalo`、`pighouse`、`spiderden` | 前期别惹牛群（`beefalo`），谨慎靠近蜘蛛巢 |

## 四、最容易踩的坑

- **黑夜没光会瞬间暴毙**：黄昏就检查手里或身边是否有火源；完全黑暗时查理（Charlie）攻击掉血极快，火堆也要记得按需添柴（`fuel`）。
- **浆果几乎不回血**：只管饱食；血低时（< 35% 别接战）靠熟肉、锅料理或药膏等**真实回血物**。
- **生蘑菇别乱生吃**：`blue_cap` / `green_cap` / `red_cap` 请视需要烤熟或入锅处理。
- **低理智刷暗影怪**：理智低于 30% 时白天多采 `flower`（每朵 +5）做 `flowerhat` 戴上，或趁安全靠火恢复。
- **复活后立刻离开原地**：复活通常只有 25% 血，原地常有杀你的蜘蛛/青蛙；先 `move_to` 逃离 4~6 格再整备。
- **战斗与偷吃**：`attack` / `kill` 血低于安全线就停手跑路；地面别乱丢食物，会被火鸡或鼹鼠偷走。
- **失败别原样硬撞**：看清失败原因（`out_of_range` 先走近，`inventory_full` 用 `container_put` 存或 `drop` 腾包，`ingredients_missing` 先补材料）。
