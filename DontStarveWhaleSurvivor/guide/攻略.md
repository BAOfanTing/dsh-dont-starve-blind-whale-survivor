# 饥荒联机版：怎么活下来（主攻略）

这份攻略是给 AI 看的。数字和名字（prefab）都尽量用游戏里的原名，方便你直接填进工具参数。

## 一、先搞清楚三件事

1. **一切以 get_state 为准**。攻略只是常识，你现在在哪、有什么、身边有什么，只有 get_state 知道。
2. **坐标是格子**。1 格 = 4 个世界单位。get_state 里写 `(12,45)` 就是 `move_to({"x":12,"z":45})`。
3. **时间是连续的**。游戏不会因为你思考而停下（除非玩家开了“思考时暂停”）。天黑之前没做完的事，就是没做完。

## 一之二、你现在能用什么

**能力清单以工具列表为准**（这份攻略只讲怎么玩，不重复参数）。按用途分：

| 用途 | 动作 |
|---|---|
| 看 | `get_state`（唯一事实来源）、`get_guide`、`update_notes`、`recipes`、`lookup`、`probe`、`inspect` |
| 走 | `move_to`、`seek`（只报位置）、`stop` |
| 采集 | `pickup`（地上的）、`harvest`（成熟浆果丛）、`gather`（草丛/树苗）、`gather_area`（一片一次采完）、`chop`、`mine`、`dig`、`hammer` |
| 制作 | `craft`（torch / axe / pickaxe / flowerhat + 科学机器旁的 rope / boards / backpack / spear / armorwood / cutstone / transistor）、`build`（campfire / firepit / chest / cookpot / sciencemachine / researchlab2 炼金引擎 / tent 帐篷）、`cook` |
| 生存 | `eat`、`equip`、`unequip`、`drop`、`fuel`、`wait`、`sleep`（在帐篷/睡袋里睡觉） |
| 交互 | `use`、`container_take`、`container_put`、`give` |
| 战斗 | `attack`（打几下）、`kill`（打到死） |
| 社交 | `say` |

`pick`、`heal`、`make_fire`、`add_fuel` 这几个名字**还没开放**，调了会报「没有这个工具」。
它们对应的能力分别用 `gather`、`eat`、`build`、`fuel` 代替。

需要 `#N` 引用的动作（采集、战斗、交互、容器）**不会自己走过去**，距离约 1 格：
够不着就先 `move_to`，**再重新 get_state** 拿新的 `#N` 和新的 Nearby 快照 ID。

### 开局最该做的一条线

1. `get_state` 看附近：草丛 `grass`、树苗 `sapling`、地上燧石 `flint`、成熟浆果丛。
2. `gather` 采 **2 丛草**（得 2 cutgrass）和 **2 棵树苗**（得 2 twigs）→ 够做火把。
3. `pickup` 捡 **1 个燧石** + `gather` 再采 1 棵树苗 → 够做斧头。
4. `craft torch`（天黑前一定要有光；空手做会直接拿在手里，不用再 `equip`）。
5. 有富余材料就 `craft axe` → `equip axe`。
6. 饿了（饥饿低于 ~50%）就 `eat`，别等掉血。

采集类动作（`gather`/`harvest`）**不会自己走过去**，而且距离只有约 1 格：
够不着就先 `move_to`，**再重新 get_state** 拿新的 `#N` 和新的 Nearby 快照 ID。

## 二、开局（第 1~3 天）的优先级

1. **先解决光和食物**：
   - 采 `cutgrass`（草）、`twigs`（树枝）、`berries`（浆果）、`carrot`（胡萝卜）。
   - 有 2 个 `log` + 3 个 `cutgrass` 就能 `build campfire`（营火）。木头靠 `chop` 砍树得来，也可以捡地上现成的 `log`。
   - 光靠火把也行：火把（`torch`）= 2 草 + 2 树枝。空手 `craft torch` 会直接装备到手上，走夜路不怕。
2. **做工具**（科学机器之前就能做）：
   - 斧头（`axe`）：1 树枝 + 1 燧石 → 能砍树
   - 镐（`pickaxe`）：2 树枝 + 2 燧石 → 能挖石头
   - 燧石（`flint`）在地上捡（`pickup`）。先 `craft axe` 再 `equip axe`，才能 `chop`。
3. **建科学机器**：`build sciencemachine`（4 木头 + 4 石头 + 1 金块）。旁边建了它，很多配方才会解锁（做东西时要站在它附近）。
4. **找金块**：`goldnugget` 在有岩石的地形和墓地，也能从 `rocks` 里挖出来。
5. **建家**：找个离牛群/猪人村/草地资源都近的地方，放 `firepit`（火坑，比营火耐用，要 2 木头 + 12 石头）、`chest`（箱子）、`cookpot`（锅，3 石头 + 6 木炭 + 6 树枝）。

## 三、白天该干什么

- **采集**：草 `grass` 和树苗 `sapling` 用 `gather`；一片区域用 `gather_area` 一次采完。
  蘑菇、胡萝卜 `carrot` 现在没有专门的 `pick`，但可以试试 `use`（不行就跳过）。
- **砍树**：`chop`（要斧头，先 `equip axe`）。`evergreen` 常青树、`twiggy_tree` 白桦，砍下来的 `log` 是木头。
- **挖矿**：`mine`（要镐，先 `equip pickaxe`）。`rock1`~`rock6`，出石头、燧石、金块、硝石。
- **打猎**：`attack` 打几下、`kill` 打到死；血低于 25% 会自己放弃。`rabbit` 兔子会跑，`pigman` 猪人会反击。
- **存东西**：`container_put` 放进箱子/冰箱，`container_take` 取出来；背包满了用 `drop` 丢掉不要的。

## 四、天黑怎么办

- 黄昏（dusk）就该准备：**火把拿在手里**，或者**身边有火**。
- 完全没有光的时候，查理（Charlie）会从黑暗里打你，掉血很快。get_state 里会提醒你。
- 火堆/火坑要加燃料（木头、草、`twigs`），否则会灭。

## 六、容易踩的坑

- **动作失败别原样重试**：先看失败原因（走不到？没有工具？材料不够？），换个目标或者先补条件。
- **背包满了**：`pickup` 会返回 `inventory_full`，`harvest` 采下来的东西会掉在地上。用 `drop` 丢掉不用的东西再捡。
- **工具会坏**：斧头/镐有耐久，get_state 的背包里会显示百分比；坏了就 `craft` 一把新的。
- **鼹鼠/火鸡会偷东西**：地面上别乱丢食物。
- **不要在没有光的时候硬撑**：宁可回家烧一堆火站着，也别在黑暗里乱跑。
- **理智低于 30% 就要处理**：白天用 `gather_area flower` 采花（每朵 +5 理智），或者回火堆旁待着；
  理智见底会刷暗影怪，残血时几乎必死。
- **别惹牛群**：`beefalo` 一群一起上，前期打不过。
- **复活后先离开原地**：复活通常只有 25% 血，原地附近往往就是刚才的死因（青蛙/蜘蛛）。
  先 `move_to` 到 4~6 格外的安全处，再补食物；别一复活就接着在原地采。
- **gather_area 别贪多**：默认只采 8 格内、最多 8 个；采集时被怪打会立刻停下。
  被打断就先用 `get_state` 看敌人在哪，`move_to` 离开，回来再采。
- **浆果几乎不回血**：浆果主要补饥饿；回血靠熟肉、药膏。血低时别指望啃浆果把命补回来。
- **死了就没了**：饥荒死亡会掉东西（除非装了复活石/重生护符）。血少于 35% 就该跑或者吃东西。
