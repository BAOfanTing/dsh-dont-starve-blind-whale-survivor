# 战斗专题

## 基本规则

- `attack` 会自动走到目标旁边、换上背包里伤害最高的武器、连续打；你只需要决定「打不打」。
- 被打到会掉血，血少于 30% 它会先吃东西（如果背包里有），吃了还打不过就告诉你跑。
- 武器有耐久，会坏；护甲（`grass_armor`、`logarmor`、`marble_suit`）能挡伤害，打硬架之前穿上。
- 打完记得捡掉落（`pick` 不了就 `go_to` 靠近再用 `pick`）。

## 打法要点

1. **一对一**：等它攻击动作结束（有硬直）再打 2~3 下。`attack` 会自动连续打，血少了要主动退。
2. **群体**：猎犬、蜘蛛、杀人蜂一群的时候，先跑到牛群（`beefalo`）、猪人村、兔人村这些天然帮手旁边，再打。
3. **打不过就跑**：跑到火堆边、跑到牛群里、进洞穴换地图，都行。血比面子重要。
4. **夜晚不要打**：晚上视野差，还容易被查理发。打完赶快回火边。
5. **护甲比武器优先**：前期 `grass_armor`（草甲，10 草 + 2 树枝）能显著减少掉血。

## 装备路线（前期 → 中期）

1. `axe` / `pickaxe`（工具，也能凑合打）
2. `spear`（长矛）：2 树枝 + 1 绳子 + 1 燧石，伤害 34，前期主力武器
3. `grass_armor`（草甲）：10 草 + 2 树枝
4. `footballhelmet`（猪皮帽）：1 猪皮 + 1 绳子，减伤好
5. `hambat`（火腿棒）：伤害高但会坏得变成腐烂食物
6. `tentaclespike`（触手尖刺）、`nightsword`（暗影剑，掉理智）

## 陷阱

- `trap`（陷阱，6 草 + 2 树枝）：放兔子洞旁边抓兔子，也能抓蜘蛛。
- `birdtrap`（鸟陷阱）：抓鸟换羽毛（做吹箭）。
- `bee mine`（蜜蜂雷）/`tooth trap`（牙齿陷阱）：放地上自动打路过的怪。
